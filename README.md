# Multi-Agent GD

**AI-Powered Group Discussion Practice Platform**

## Overview

**Multi-Agent GD** is a web application that helps students practice **Group Discussions (GD)** anytime using multiple AI participants. Instead of waiting for friends or classmates, users can create a virtual discussion room where AI participants communicate naturally with each other and with the user.

After every discussion, the platform analyzes the user's communication skills and provides personalized feedback to help improve placement readiness.

---

## Features

### Authentication

* User Signup & Login
* Secure Authentication

### Create Discussion

* Select or enter a custom topic
* Choose discussion mode
* Select language
* Set discussion duration
* Configure 2–5 AI participants

### AI Participants

* Custom AI names
* Gender selection
* Different personalities
* Different speaking styles
* Natural AI-to-AI conversation
* AI interacts directly with the user
* Follow-up questions and logical responses

### Discussion Room

* Voice-based discussion
* Live transcript
* Speech-to-Text
* Text-to-Speech
* Speaking timer
* Pause detection

### AI Feedback

* Overall performance score
* Fluency analysis
* Grammar evaluation
* Confidence score
* Vocabulary analysis
* Speaking speed
* Filler word detection
* Topic relevance
* Personalized improvement suggestions

### History

* Previous discussion sessions
* Performance tracking
* View past feedback reports

### Profile

* User information
* Practice statistics
* Average score
* Discussion history
