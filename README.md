# 🎙️ Multi-Agent GD

**AI-Powered Group Discussion Practice Platform**

🔗 **Live Demo:** https://multi-agent-gd.onrender.com

## About
*Built to help students prepare for placement group discussions through AI-powered practice.*

Multi-Agent GD helps students practice placement group discussions with **2–5 AI participants** featuring different personalities and speaking styles. Users can participate through voice and receive AI-generated feedback to improve their communication skills.

## Features

- **AI Participants:** Multi-agent conversations with diverse personalities.
- **Voice-Based GD:** Speech-to-text, text-to-speech, and live transcripts.
- **Custom Discussions:** Choose topics, language, duration, and participants.
- **Multilingual Support:** English, Hindi, and Hinglish.
- **AI Feedback:** Analysis of fluency, grammar, vocabulary, confidence, and filler words.
- **Session History:** Review previous discussions and feedback.
- **Authentication:** User signup and login.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **AI:** Groq API (`gpt-oss-20b`) for AI participants and feedback analysis
- **Voice:** Web Speech API (Speech-to-Text) and Speech Synthesis (Text-to-Speech)
- **Authentication:** JWT, with passwords hashed using bcrypt
- **Security:** API rate limiting (express-rate-limit), CORS
- **Deployment:** Render
